# beng-182: Biological Data Analysis

UCSD Bioinformatics class taught by Professor Vineet Bafna. This course is about understanding sources for Biological Data, and the tools used to query them. 
The course synthesizes material from other classes. In Math 186 (Glenn Tesler), we learned the basics of statistical analysis; in CSE 181 (Pavel Pevzner), we learned the algorithmic principles used to build Bioinformatics tools; in BENG 183 (Sheng Zhong) it's explained how modern instruments generate biological data. In this class, we learned how tools were constructed from these principles, and how they can be used to make biological discoveries.

Code from Assignments and Projects are uploaded in this repository.
